# pymongo-api

## Как запустить

Запускаем mongodb и приложение

```shell
docker compose up -d
```

Инициализируем конфигурацию инфраструктуры

```shell
./scripts/01-init_infrastructure.sh
```

Заполняем mongodb данными

```shell
./scripts/02-init_data.sh
```

Проверка данных

```shell
./scripts/03-check_data.sh
```

## Как проверить

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8090

### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8090

## Доступные эндпоинты

Список доступных эндпоинтов, swagger http://<ip виртуальной машины>:8090/docs
